# What changes for maintainers

Write this section for a developer about to read the diff. Use technical terms and name the code: packages, classes, modules, commands,
rules, and patterns.

Give one bullet per change as before → after, then one line on what it prevents or speeds up, for example: "`AppearanceColors` and
`EquipmentSlots` become `readonly`; both appearance requests build them with `AppearanceColors::fromRequest()` instead of Laravel Data
casting." Never paraphrase code in user-story prose ("objects any code could change") or open with "Users notice nothing".
