## Workflow

1. Record intentionally postponed work in the project's `TECH_DEBT.md`; create the file when needed.
2. Use one unchecked task per item. State what remains, why it is postponed, where it applies, any version limits, and how to complete the cleanup.
3. Remove the item when the work is resolved.
