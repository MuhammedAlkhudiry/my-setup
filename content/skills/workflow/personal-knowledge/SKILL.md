## Source routing

- When `pk` is available, use `pk --help` for commands and options.
- Otherwise, locate the personal-knowledge repository with a connected GitHub tool. Prefer the named repository; otherwise identify it from
  its purpose and root documentation rather than guessing.
- Read the repository's instructions, index, and narrowest relevant sources before answering or changing anything.

## Workflow

1. Search for the requested information and check notes against newer or more authoritative entries.
2. Answer from the strongest evidence; state when it cannot support an answer.
3. Create or update knowledge only when the user asks. Follow the repository's structure and rules for writing and indexing notes.
4. Use a connected write tool only if it supports the required operation. Otherwise return the exact proposed change and say it was not saved.
