# Lanes Menu

A native macOS menu-bar control surface for canonical and task runtime environments.

## Boundary

This module is a thin native client for the installed `lanes` JSON contracts. Runtime state, resources, services, logs, and actions belong to the CLI;
Swift client, view, and packaging belong to this directory. Shared installation belongs to [menu-apps.ts](../../lib/menu-apps.ts). The app does not
create, delete, or otherwise manage Git worktrees.
