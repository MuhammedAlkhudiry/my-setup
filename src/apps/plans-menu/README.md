# Plans Menu

A native macOS menu-bar app for finding, reviewing, editing, and archiving saved plans.

## Boundary

This module is a thin native client for the installed `lanes plans` JSON and action contracts. Plan discovery, persistence, indexing, and archiving
belong to the CLI; Swift client, view, and packaging belong to this directory. Shared installation belongs to [menu-apps.ts](../../lib/menu-apps.ts).
